# Forge task progress

This Forge desktop preview does not ship a Python `statusline.py` command or a supported CLI status-bar integration.

Use the application’s task details and activity panels to inspect actual run progress. Do not install a status-line command that references a nonexistent source directory, and do not interpret a stale local status file as a running task.

For supported development and launch commands, see [README.md](../../README.md). For source provenance and license information, see [UPSTREAM.md](../../UPSTREAM.md).
