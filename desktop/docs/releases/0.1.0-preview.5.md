# Forge 0.1.0-preview.5

实际开发与发布验证日期：**2026-09-29**。本版为 **macOS arm64 · INTERNAL / ADHOC / UNNOTARIZED 预发布**，集中修复桌面控件、模型配置及失败恢复。

## 本版更新

- **模型配置提供真实测试按钮。**未保存配置和已保存账户均可显式测试；显示等待、成功、认证／配额／超时等结果，修改配置后旧结果失效。Z.AI 的最小模型测试有费用／配额说明；OAuth、Bedrock 等不支持的测试明确提示当前边界。
- **模型与 Ollama 配置准确生效。**补端点校验，保留真实 provider 与 billingModel；模型发现、记忆 embedding／reranker 使用实际配置端点，连接和初始化失败可重试。跨 provider 只由用户显式开启。
- **向导与项目初始化可恢复。**完成向导先保存，失败保留原动作；创建任务衔接正常项目入口；Git 与 Forge 初始化按顺序显示，目录选择异常有反馈。
- **洞察补齐复制、再生成、停止和重试。**结果绑定项目、会话和请求，停止等待执行／工具／子进程关闭；图片规范化进入 SDK，建议任务真实持久化并去重。
- **任务操作遵守真实结果。**状态文件保存失败不推进成功；任务自动推送选择同时保存 true／false 并覆盖项目默认；审查失败保留输入，文件、IDE、工作树及批量 PR 失败可重试。
- **想法、路线图与终端恢复更完整。**归档想法可恢复并保留任务链接；路线图转换保持真实 planned／backlog。终端恢复失败保留当前会话，初始失败不再循环请求，支持明确重试和键盘重排。
- **集成及可访问性修复。**GitHub／GitLab／Linear 开关保存并重读，既有 GitHub／Linear IPC 尊重关闭选择；补控件标签、键盘、复制等待及错误反馈，两主题终端文字对比度复验通过。
- **验证与文档整理。**回归工具隔离用户配置，测试证据只在清理及原配置校验完成后记录成功；普通打开优先本版应用，删除重复一次性报告，保留实施状态与原始证据。

没有新增依赖、SQL migration、网络监听或自动更新；应用 ID 与 `Forge Glass Preview` 数据目录保持不变，不重置用户 SQLite、项目或运行记录。

## 下载安装

[下载 DMG、ZIP、对应源码和 SHA256SUMS](https://github.com/j-tide/Forge/releases/tag/v0.1.0-preview.5)。核对摘要后保存工作、正常退出旧 Forge；打开 DMG 并将 `Forge.app` 拖入 Applications，或解压 ZIP 后正常打开。

此包使用 ad-hoc 签名，未公证，遵循 macOS 自身安全提示，不全局关闭 Gatekeeper。模型调用需要合法认证、网络及相应费用授权；配置或测试成功不等于完整 Agent 执行通过。

仓库根 `pnpm desktop:open` 或独立 Desktop `npm run preview:open` 优先选择 `dist/0.1.0-preview.5/mac-arm64/Forge.app`。历史包保持原样。

## 未关闭风险

- **衍生桌面尚未接通 Forge Python Host，活跃 Agent worker 尚未接通项目 `.env`／MCP override 链。**正常集成 IPC 的开关修复不代表该 Agent 路径已实现。
- 完整真实 Task／Idea／Roadmap／Changelog 闭环、外部 OAuth、Ollama 安装／下载、远端 PR／合并／部署、全部 provider 及 Claude 仍未由本次验证证明。任务自动推送选项只控制既有工作树初始化参数，不承诺阻止模型所有任意 Shell 远程动作。
- Windows、macOS Intel、正式签名／公证／更新及完整 Forge 产品验收保持未通过；手机、Companion、远程与跨设备新增工作继续后置。
- 生产依赖审计仍为 **33 项：10 high／9 moderate／14 low／0 critical**；没有新增依赖，也没有将继承风险标记为修复。
- 早期本地 QA 曾覆盖共享剪贴板且未保存原内容，无法还原；后续测试加入每次操作的格式／内容恢复保护。它是已披露的本地测试遗留，不能表述成整轮剪贴板未变。
