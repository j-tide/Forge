Status: Accepted for P5-11 development scope on macOS arm64, 2026-09-25.

## 2026-09-27 installed Standard and immutable delivery provenance

The disposable source repository remained clean. This is a real installed Standard path, not inferred from publication or fixture tests. The accepted Standard delivery revealed a read-model discrepancy: existing summaries always said `not_configured` and counted Plan and Developer Runs together as Developer Attempts. Old summary rows and frozen RunConfigs are not rewritten. The UI labels the prior count as Run records and says when a legacy summary did not record Plan provenance, without claiming no Plan ran. This source fix needs a new installed-package check and introduces no new Renderer privilege, business transition or schema migration.

Node labels and bound Developer/Reviewer Profiles may differ; node semantics, routes, retry/rework limits, outputs and budgets may not. Planner, conditions, arbitrary commands and other graph shapes fail closed at launch. Publication is a static validation step, not permission to run every published graph. Each stage remains an explicit user/API action with real evidence; no hidden automatic Review, Verify or owner acceptance is claimed.
