# ADR 0086 · 视频磨砂视觉与现行桌面交互结构

状态：用户批准，实施中（2026-09-27）。

## 背景

用户要求 Forge UI 回到先前提供的视频设计风格，并特别关注动效，同时明确需要亮色与暗色。ADR 0085 已推动项目原位选择、单一新建任务入口、五列看板和任务详情等交互结构；这些改动解决了此前的可用性问题，但其偏硬、偏平的视觉处理没有体现用户视频中的雾面材质和轻柔转场。

原始参考为用户先前提供的 `2026-08-27_09.02.16_短耳兔设计_UI设计灵感分享_磨砂玻璃风格UI动效参考.mp4`。仓库内 `forge_glass_v1.1/design/visual-spec.md` 记录了视频观察和设计转译，`design/tokens.json` 与 `design/motion.json` 是可核对的视觉、动效参考；`forge_glass_walkthrough.mp4` 是基于该方向制作的 Forge 原型演示，不是原始视频，也不是生产客户端。

## 决定

- **视觉和动效**以用户原视频为方向，结合 `forge_glass_v1.1` 的视觉规格与动效参数独立实现：银白、浅蓝灰、柔和环境光、圆润轮廓、低透明度雾面、细微内高光、清晰的高不透明度阅读表面和克制的反馈。恢复其材质和节奏，不照搬视频品牌、壁纸或演示画面。
- **信息架构和操作路径**继续沿用 ADR 0085 中已改善的桌面结构：紧凑侧栏、原位项目选择、单一新建任务入口、五列看板、分区任务详情和明确模型/角色信息。Aperant 2.x 仍是交互密度的对照，不再决定 Forge 的颜色、材质和动效。ADR 0085 关于 glass v1.1 仅为历史参考及 Aperant 视觉优先的条款由本 ADR 覆盖；其产品语义、安全边界和独立实现原则保持有效。
- **亮色与暗色**使用同一页面结构和组件语义。亮色还原视频的银白蓝灰雾面语言，新安装默认亮色；暗色是同一设计语言的可读蓝灰变体，不回到旧铜橙、纯黑重侧栏或霓虹玻璃。现有设置中的亮色、暗色、跟随系统继续有效，已保存的用户选择不被新默认值覆盖。生产设计 token 仍由 `packages/ui/src/tokens/` 维护，参考 JSON 不成为运行时依赖。
- **动效**以 `forge_glass_v1.1/design/motion.json` 为起点：页面约 330 ms / 7 px、卡片 hover 约 200 ms / 最多上浮 3 px、对话框约 320 ms / 18 px / 从 0.985 缩放、抽屉约 350 ms / 从右侧 30 px。按实际内容和窗口性能调整时保持轻短、可中断，不连续动画化玻璃模糊半径、整窗透明度或背景。状态改变必须由真实 Host 回执驱动，动画不暗示尚未发生的成功。
- **可访问性回退**：系统 `prefers-reduced-motion` 与 Forge 减少动效设置均关闭非必要位移和缩放，保留即时状态反馈；减少透明度使用同布局的实色表面，保持文本和焦点可读。键盘、中文输入法、弹层焦点、不同窗口宽度以及 macOS/Windows 原生标题栏边界继续验收。
- 继续使用 Electron + Vue + `@forge/ui` 与真实 Python Host。资料包、原型 HTML、视频帧和示例数据不得直接成为生产页面或业务结果。P7/P8 手机与远程新增开发仍后置。

## 验证门槛

从真实 Web 与 Electron Renderer 分别核对亮色、暗色及跟随系统；在 1440×900、1600×1000 和较窄窗口检查主要页面、抽屉与弹层。捕获实际运行截图，并对开合/切换录制短时序或使用浏览器计算样式检验时长、方向和焦点。分别验证系统及手动减少动效、减少透明度。旧 Aperant 风格内部包及 `forge_glass_v1.1` 的参考截图不能充当这次实现的验收证据；完整桌面产品与发布门禁仍按各自记录判断。
