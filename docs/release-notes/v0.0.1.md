# Forge v0.0.1 — P0-01 工程基线

这是 Forge 的首次工程基线发布，不是可安装或可启动的客户端。

## 包含

- 保留产品/工程规格 `forge_spec_v1.0/` 与新版视觉方向 `forge_glass_v1.1/` 作为只读实施依据。
- 建立 pnpm workspace、strict TypeScript、公开的 `@forge/contracts` 入口和精确版本锁定。
- 提供冻结 lockfile 安装、lint、typecheck、test、build 命令与最小 CI。
- 记录工具链版本、许可证、实施状态和后续兼容性验证矩阵。

## 验证范围

本机 macOS arm64：`pnpm install --frozen-lockfile`、`pnpm lint`、`pnpm typecheck`、`pnpm test`（3 项）、`pnpm build` 均通过。GitHub Actions 工作流已配置，云端结果以实际运行记录为准。

## 尚未包含

Desktop、Web、Host、模型与 Agent 执行、数据库、看板及真实审批流均未实现。T001–T005 与 Windows/macOS 客户端兼容性待后续任务验证。
