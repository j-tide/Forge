# 0.1.0-preview.2 · 中文界面与语言切换

实际修改与验收日期：2026-09-28。内部 macOS arm64 预览，ADHOC / UNNOTARIZED。基于 Aperant `v2.8.0-beta.6`；不代表原 Forge Python Host 完整产品验收。

## 交付内容

- 中文覆盖任务／审查／看板、应用／项目设置、智能体配置、上下文／知识／记忆、洞察／创意／路线图／更新日志、GitHub／GitLab／Linear、终端／工作树／MCP、首次使用及原生菜单／通知／应用错误提示。
- 设置 → 语言：中文 / English 按钮即时切换、仅保存语言字段、重启保留。失败显示错误，不把保存失败冒充成功；正在保存时禁止重复点击。不丢失其他尚未保存的设置草稿。
- 新用户默认中文；已有语言和亮／暗主题不覆盖，旧法语设置兼容保留。系统拼写检查不对中文应用英文词典。
- 用户文本、品牌、模型 ID、代码、命令、目录及外部 provider 输出保持原文；不变更模型配置、授权、数据结构、Task 状态或工作流。
