# Forge 0.1.0-preview.3

实际开发与验证日期：2026-09-28。此版本是 **macOS arm64 INTERNAL / ADHOC / UNNOTARIZED 预览版**，不是完整 Forge 产品或正式发行验收通过。

## 本版变更

- 桌面源码归入公开 Forge 仓库的 `desktop/`；保留独立 npm workspace、完整上游历史、AGPL-3.0 许可与来源声明。原仓库的 Python Host、Vue 实现、规格和用户数据不删除。
- 普通界面、应用元数据、MCP/tool namespace、项目内部名称采用 Forge；旧配置的读取兼容保持。API Profile 使用 Forge 私有路径，旧文件只在新文件缺失时兼容读取，不删除原文件。
- 新 Forge F 标识用于侧栏、欢迎、向导、关于、favicon、Dock/Finder 及各平台图标；亮暗主题共用轮廓。
- 完整中文界面及设置中的中文／English 切换继续保留。语言与主题经过真实 Electron 重启测试。
- 源码按钮指向公开的 `j-tide/Forge/tree/main/desktop`；继承的自动发布、更新、遥测上传和上游预构建下载保持关闭。新安装包从当前 0.1.0-preview.3 编译结果生成，未修改旧 Release 资产。

## 安装与启动

从 [Forge v0.1.0-preview.3 Release](https://github.com/j-tide/Forge/releases/tag/v0.1.0-preview.3) 下载 macOS arm64 INTERNAL DMG 或 ZIP。DMG 中将 `Forge.app` 拖入 Applications，或解压 ZIP 后普通打开；不会像 smoke 自动退出。应用使用 `~/Library/Application Support/Forge Glass Preview`，不迁移或重置原 Forge SQLite。

此包未公证；遵循 macOS 自身的安全提示，不全局关闭 Gatekeeper。Git 及所选提供方的合法认证为外部前置条件，不能因打开窗口就认为 Agent 可用。本版 QA 没有调用模型、使用 Claude 凭据或消耗新的在线额度。

源码仓库本地运行：根目录 `pnpm desktop:open` 打开本版构建；在 `desktop/` 下执行 `npm run dev` 开发衍生桌面。原根目录 `pnpm dev:desktop` 仍对应历史 Vue/Python 实现，二者不混用。

## 未关闭风险

- 衍生桌面尚未接入 Forge Python Host，原 Forge 的 Task/Run/Review/Verify/人工接受历史验收不适用于此预览包。不能宣称完整桌面或全部业务链通过。
- Windows x64、macOS Intel、正式 Developer ID 签名、公证、签名更新与迁移、Claude 在线验收仍 UNVERIFIED/BLOCKED；未新增相关支持声明。手机/远程新增开发继续后置。
- `npm audit --omit=dev`：33 项继承生产依赖风险（10 high、9 moderate、14 low、0 critical）；未以品牌改名掩盖或记为解决。
- 提交时间按照用户要求延续上次时间，每次随机间隔 1～3 天；这是仓库排期元数据，实际开发/验证日期仍为 2026-09-28。

Release 同时提供对应完整源码 archive 与 SHA256SUMS。AGPL 来源与版权说明在 `desktop/LICENSE`、`desktop/UPSTREAM.md` 和应用内法律说明中保留。
