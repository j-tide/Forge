# Forge 0.1.0-preview.4

实际开发与验收日期：**2026-09-28**。本版为 **macOS arm64 · INTERNAL / ADHOC / UNNOTARIZED 预发布**，集中交付桌面视觉与交互修复。

## 本版更新

### 更清楚的工作台

- 银灰亮色与石墨暗色统一导航、排版、表单、圆角和焦点；磨砂集中于外壳，阅读区域使用稳定表面。
- 紧凑侧栏按工作、探索、项目分组，保留单一新任务入口；新建任务将需求与执行配置并列，小窗口保持滚动可达。
- 看板根据实际滚动范围显示首尾导航；项目设置和应用设置保持在工作台内，关闭后返回正确入口。
- 系统与用户的减少动效、减少透明度均有效；语言、主题和偏好在重启后保留。

### 修复明确的交互问题

- **项目旁的配置按钮只打开当前项目设置**；左下角打开全局应用设置。项目保存不会写入全局偏好，快捷键不会在设置页误触任务操作。
- Tooltip、用量面板、模型与仓库／分支菜单使用 Portal；长弹层不越出窗口，账户末项可滚动到达，按钮不被压成多行。
- `@文件` 补全跟随输入位置，中文文件及同名目录保留完整相对引用；键盘、Escape 与焦点恢复正确，越界路径拒绝。
- 草稿保存并读回基准分支、工作树和模型等配置；分支不可用或探测失败时不悄悄回退。
- Context／记忆、Insights 与 MCP 的异步结果绑定实际项目／会话，切换后不显示旧项目数据；保存、健康检查与生成失败不会显示假成功。
- 删除预检没有完成或失败时阻止删除，保留重试；路线图保存失败保留原数据，详情侧板支持键盘与焦点。
- 无认证账户时不显示虚假的无限额度；当前 API 账户不可测的额度不冒充真实 provider 使用量。

保留 `.3` 的 Forge 标识、中英文、旧配置兼容与隔离数据目录；没有新增依赖、SQL migration、网络监听或在线模型调用。

## 下载安装

[下载本版 DMG、ZIP、对应源码和 SHA256SUMS](https://github.com/j-tide/Forge/releases/tag/v0.1.0-preview.4)。

1. 根据发布页 `SHA256SUMS` 核对文件。
2. 保存工作并正常退出旧 Forge。
3. 打开 DMG，把 `Forge.app` 拖入自己的 Applications 文件夹，或解压 ZIP。
4. 从 Finder 正常打开新版；应用会常驻，不使用自动结束的 smoke 入口。
5. 在首页打开可丢弃 Git 项目；在应用设置中配置自己的合法账户与所需工具，再明确决定是否执行任务。

此包未公证，遵循 macOS 自身的安全提示，不全局关闭 Gatekeeper。项目操作需要 Git；模型调用需要所选 provider 的有效认证、网络与可能需要的 CLI。打开应用并不意味着 Agent 已可用。

应用 ID `dev.iamzjt.forgeglasspreview` 与 `~/Library/Application Support/Forge Glass Preview` 保持不变。升级不重置原 Forge SQLite，不删除旧配置，不修改既有冻结 Run。

源码构建后，根目录 `pnpm desktop:open` 或 `desktop/` 中的 `npm run preview:open` 优先打开本版。原 `pnpm dev:desktop` 对应历史 Vue／Python 工程，不能当作当前衍生包的验证入口。

## 未关闭风险

- **当前衍生桌面尚未连接 Forge Python Host。**完整 Task／Run／Planner／Review／Verify／最终人工接受的原 Forge 历史证据不能直接用于本版支持声明。
- 当前版本的完整在线任务闭环、外部 MCP、第三方集成、真实 provider 额度与 Claude 验收没有由本次无费用 UI 回归证明。
- Windows x64、macOS Intel、系统 DPI／辅助技术仍未实机验证；Developer ID、公证、签名更新与正式迁移验收保持未通过。
- production npm audit 继承风险仍为 **33 项：10 high／9 moderate／14 low／0 critical**。本版没有增加依赖，也没有宣称修复这些风险。
- 手机、Companion、远程与跨设备新增开发继续后置；没有为预览发布开放网络或放宽权限。
