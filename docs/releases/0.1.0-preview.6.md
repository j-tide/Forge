# Forge 0.1.0-preview.6

实际开发与发布验证日期：**2026-09-29**。本版为 **macOS arm64 · INTERNAL / ADHOC / UNNOTARIZED 预发布**，删除旧 Forge 实现，并将保留的 Aperant 衍生桌面重组为根目录单一 npm 应用。

## 本版更新

- **只保留当前桌面工程。**按用户要求删除旧 Vue/Electron 桌面、Python／TypeScript Core、Node Host、插件、契约、任务图、旧验收资料及 pnpm 工具。当前运行路径是 React Renderer → Preload `electronAPI` → Electron Main IPC → TypeScript Agent Workers / Vercel AI SDK；已删除的 Python Host 不再是待接入架构。
- **源码与 npm 工程移到根目录。**使用单一 `package.json` 和 `package-lock.json`；产品代码归 `src/main`、`src/preload`、`src/renderer`、`src/shared`，资源与提示词归 `resources/`、`prompts/`，辅助脚本与独立测试归 `scripts/`、`tests/`。不再保留 `desktop/` 或 npm workspace 外壳。
- **修正实际构建与运行路径。**Worker、共享提示词 loader、源码识别和打包入口适配根布局；安装包从运行时资源位置读取提示词，开发与打包应用使用各自真实路径。新增 26 项回归覆盖根路径、共享 chunk、Main／Worker 提示词资源及开发源码识别。
- **更新开发、检查与来源入口。**唯一 CI 为根 `.github/workflows/desktop-quality.yml`；当前文档归 `docs/`，源码／许可入口和打包脚本指向根工程。历史版本文档、tag、安装包、源码附件及其摘要保持发布时事实。

应用 ID `dev.iamzjt.forgeglasspreview`、`Forge Glass Preview` 用户数据目录及项目 `.forge-glass-preview/` 身份保持不变。结构整理不迁移、不重置、不删除真实用户设置、账户、项目、任务或数据库；应用依赖版本与 integrity 保持，未新增依赖版本。自动上游更新、自动发布及默认错误上报继续关闭。

## 下载安装

[下载 DMG、ZIP、对应源码和 SHA256SUMS](https://github.com/j-tide/Forge/releases/tag/v0.1.0-preview.6)。核对摘要后保存工作、正常退出正在运行的 Forge；打开 DMG 并将 `Forge.app` 拖入 Applications，或解压 ZIP 后正常打开。

此包使用 ad-hoc 签名，尚未公证，请遵循 macOS 自身安全提示。模型调用需要有效认证、网络及相应费用授权；配置或最小连接测试成功不代表完整在线 Agent 执行通过。

开发与检查命令均在仓库根执行。正常打开本版可使用 `npm run preview:open -- dist/0.1.0-preview.6/mac-arm64/Forge.app`；默认命令依次查找根 `dist/mac-arm64/Forge.app` 和当前版本目录，具体打包路径及实际结果以本节验证记录为准。

- **活跃 Agent Worker 尚未接通项目 `.env`／MCP override 配置链，也未完整接入新 libSQL 记忆服务。**Main 的记忆 IPC 或配置页面存在不代表 Worker 已使用该配置。

- 本版仅交付 macOS arm64 内部包。Windows、macOS Intel、其他目标平台、正式 Developer ID 签名／公证及更新通道未由本轮验证证明。手机、Companion、远程与跨设备新增开发继续后置。
- 继承依赖风险以本轮审计记录为准；本次结构整理没有宣称修复全部依赖问题。
