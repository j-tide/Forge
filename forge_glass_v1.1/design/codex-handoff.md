# 给 Codex 的设计迁移任务

## 目标

在原有 Forge 产品/工程边界不变的前提下，改造 Desktop 的视觉和页面组织。以本包 HTML、截图和视觉规格为新方向；不要照着旧铜橙/深色侧栏稿继续实现。

本包是方向稿，不表示用户已经批准最终像素细节。先交付 Board + DraftDialog + TaskDrawer，复核后再同步次级页面。

## 先读

- 原实施包 `AGENTS.md`、任务/审批/Run/插件相关契约。
- 本包 `README.md` 与 `design/visual-spec.md`。
- 本包 `forge_glass_prototype.html`；将它作为行为和样式参照，不直接把单文件脚本移植为产品架构。
- `screens/01-board.png`、`02-approval.png`、`03-task-activity.png`、`04-workflow.png`。

## 模块拆分建议

| 组件 | 职责 | 不能承担 |
|---|---|---|
| AppShell / WindowMaterialAdapter | 窗口材质、标题栏、安全 IPC | 执行 Agent / 修改任务状态 |
| IconRail | 主路由选择与提示 | 在导航时触发任务 |
| CommandPanel | 自然语言输入、草稿摘要 | 绕过审批立即开工 |
| DraftDialog | 编辑合同、显示差异、请求批准 | 用前端本地状态冒充已落库审批 |
| TaskBoard / TaskCard | 展示状态与筛选 | 以拖拽绕过阶段条件 |
| TaskDrawer | 需求、活动、代码差异与检查 | 重新解释已经冻结的版本 |
| CurrentRunBar | 对应 Run 的近期事件 | 猜测执行完成或生成假日志 |
| WorkflowCanvas / StepInspector | 编辑声明式流程草稿 | 改写运行中配置 |
| AgentProfiles / PluginPanel | 兼容选择与权限申请 | 静默授予系统权限 |
| GlassSurface / PillButton / StatusTag | 统一材质与交互 | 承担业务状态机 |
| CompanionViews | 窄屏待办与审批 | 执行本地代码或离线排队审批 |

建议按 Vue SFC 提取，只共享设计 token 和展示组件，不把业务 Host 塞进组件。

## 六个实施任务

### UI-01：材质系统和窗口壳

加入统一 CSS token 与三种表面（shell/panel/reading），移除旧深侧栏与铜橙；保持正确滚动和响应式。先提供一致的实色回退。原生材质作为独立可失败的增强项。验收：1440×900、1600×1000 主界面不溢出；减少透明度不损坏页面。

### UI-02：聊天 + 看板

提取左栏和五列看板，事件、状态与计数读取真实查询数据。标题过长可折行，不用极小字号。对输入内容进行文本安全渲染；不让 Markdown 嵌入危险 HTML。验收：审批前卡片不进入 TODO；新卡片从 Host 响应插入，批准不自启动。

### UI-03：审批与任务详情

审批采用中央面板，任务详情使用右侧抽屉。任务/合同/快照版本仍由内核确定；编辑后重新审批。应用焦点管理与中文 IME 保护。验收：取消不提交；无效字段无法批准；检查必须关联当前版本；Done 不等于 Merge。

### UI-04：次级页面

统一工作流、角色/插件、知识、项目、远程和设置。保留插件化契约，不因原型里只有两个执行器选项而写死正式能力列表。端点未接好则显示未配置/离线，不显示伪造成功。

### UI-05：动效与跨端

仅在适当事件发生时播放短动画；支持 reduced motion 和减少透明度。原生窗口控件因平台不同分别适配；展示壁纸不作为默认产品壁纸，除非用户选中内置背景模式。手机优先待处理列表，不强制横向看板。验收含明暗背景、长文本、系统缩放、弱性能设备。

### UI-06：质量验证

对本包 30 项原型检查转换为正式 E2E：删除“演示状态”判定，替换为 Host 回执和真实契约校验。补足空态、错误态、离线、审批过期、执行器取消未确认、字体放大、读屏与真实 OS 材质测试。

## 不变的要求

Forge 和 ProofRun 完全独立。不要在 UI 改造中引入自主测试系统、改插件契约、简化授权、绕过写入锁、替换当前 Run 版本、扩大手机权限，或一次性重构整个 Host。

## 第一条可直接发送的指令

请阅读原 Forge 的 AGENTS.md 和本包 design/codex-handoff.md。仅实施 UI-01 与 UI-02：把现有 Desktop 壳和研发看板迁移为本稿的银白雾面玻璃设计，使用真实数据接口，不复制演示任务或假日志。保持产品契约和内核不变。完成后提交变更文件、1440×900 与 1600×1000 截图、减少透明度截图、实际执行的检查、尚未验证项。不要提前实现 UI-04–UI-06。
