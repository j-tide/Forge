# Context Bundle 装配与记忆写入基线

优先序：不可覆盖的运行政策、当前用户已批准合同、明确人类决定、当前代码与工具观察、版本匹配项目规范、历史记忆/参考资料。

每项资料带sourceId/revision/hash/projectId/trust。先授权/范围过滤，再做检索；输出上限按token budget。使用哪个模型只影响token估计器，不允许预算不足时静默删掉安全政策和验收条件。

历史记忆不是现在的事实。与当前观察冲突时记录冲突并降级/撤销过期记忆，不从多次重复的错误里推断“高可信”。没有来源的结论不能成为已确认项目规则。

RAG基础路线：MD/TXT/OpenAPI → 结构化段落 → 清洗并保留原文映射 → 项目/环境/版本过滤 → FTS5（中文预分词与代码标识符） → 引用核验 → 上下文。向量与RRF只在P9经标注检索集证明收益后启用。

写入ProjectMemory：仅propose(candidate)。由人确认或白名单确定性验证器进行晋升。来源撤销、路径变化、环境变化触发stale/revoked；禁存credential、Cookie、真实隐私表。跨项目经验默认关闭。
